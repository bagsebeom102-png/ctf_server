# DH CTF

고등학교/동아리용 간단한 CTF 플랫폼입니다.

## 기능
- 회원가입 / 로그인
- 기본 관리자 계정
- 시스템 해킹 / 리버싱 / 웹 해킹 / 암호학 각 2문제
- 플래그 제출 및 풀이 기록
- 관리자 페이지에서 사용자별 풀이 현황 확인
- 쿠키 변조 실습
- SQL Injection 실습 (별도의 샌드박스 DB만 사용)

## 실행

```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Linux/macOS:
```bash
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

브라우저:
http://127.0.0.1:5000

## 기본 관리자
- ID: admin
- PW: admin1234

공개 서버에 올리기 전에 반드시 환경변수로 바꾸세요.

Linux/macOS:
```bash
export ADMIN_PASSWORD='강한비밀번호'
export SECRET_KEY='아주긴랜덤문자열'
python app.py
```

Windows PowerShell:
```powershell
$env:ADMIN_PASSWORD="강한비밀번호"
$env:SECRET_KEY="아주긴랜덤문자열"
python app.py
```

## 주의
시스템 해킹 문제는 실제 운영체제 권한 상승 취약점을 만들지 않습니다.
웹 SQLi 문제도 별도의 challenge_sqli.db만 사용하여 메인 회원 DB와 분리했습니다.


## 관리자 현황 페이지

`admin` 계정으로 로그인하면 `/admin`으로 자동 이동합니다.

관리자 페이지에서:
- 참가자 수
- 전체 문제 수
- 전체 풀이 수
- 전체 배점
- 참가자별 문제 풀이 여부
- 각 문제 풀이 시간
- 참가자별 획득 점수
- 문제별 풀이율

을 확인할 수 있습니다.

관리자 페이지의 **새로고침** 버튼을 누르면 최신 현황을 다시 불러옵니다.


## 이번 업데이트
- 사이트 입장 비밀번호: 환경변수 `SITE_PASSWORD` (기본값: `dhctf2026`)
- 관리자 페이지에서 참가자 IP 확인 가능
- 관리자 페이지에서 참가자 비밀번호 재설정 가능
- 관리자 페이지에서 참가자 추방 가능
- 관리자 페이지에서 문제 정답 확인 가능
- 참가자 원래 비밀번호는 해시로 저장되며 평문으로 노출하지 않음
- 문제 설명의 줄바꿈을 `<br>` 문자열이 아닌 CSS로 처리
- Cookie 문제의 직접적인 힌트 제거
- 리버싱 문자열 문제 파일에 여러 디코이 문자열 추가
- 리버싱 연산 문제 난이도 상향
- ROT28 / XOR / SQL Injection 기초 문제는 유지

### 환경변수 예시
`SITE_PASSWORD=원하는사이트비밀번호`
`ADMIN_PASSWORD=원하는관리자비밀번호`
`SECRET_KEY=긴랜덤문자열`


## 사이트 접속 비밀번호
사이트의 첫 화면(`/`)에 접근하면 먼저 `/site-access` 비밀번호 입력 화면이 표시됩니다.
비밀번호가 맞아야 CTF 사이트로 들어갈 수 있습니다.

기본 비밀번호:
`dhctf2026`

운영 시에는 환경변수 `SITE_PASSWORD`를 원하는 비밀번호로 변경하는 것을 권장합니다.


## v6 변경 사항
- 사이트 접속 비밀번호와 CTF 로그인 비밀번호를 분리했습니다.
- 사이트 접속 비밀번호는 브라우저 세션에서 한 번만 입력합니다.
- CTF 로그아웃을 해도 사이트 접속 인증은 유지됩니다.


## v7 변경 사항
- 시스템 해킹 문제 파일에서 flag가 직접 노출되지 않도록 수정했습니다.
- 가상 터미널에 `cd`, `chmod`, `pwd`, `ls`, `ls -l`, `cat`, `sudo -l`, `whoami`, `id`, `find` 등을 추가했습니다.
- `cd`로 현재 작업 디렉터리가 변경되며 상대 경로도 사용할 수 있습니다.
- `chmod`는 가상 파일 권한만 변경하며 실제 서버 파일에는 영향을 주지 않습니다.
- 시스템 1번은 `sudo -l`에서 허용된 `/bin/cat`을 확인한 뒤 `sudo cat /opt/ctf/root_flag.txt`로 해결할 수 있습니다.
- 시스템 2번은 파일 권한을 확인하고 `chmod`로 가상 파일 권한을 변경한 뒤 읽는 방식으로 풀 수 있습니다.
- 터미널 프롬프트와 명령어 입력창을 같은 줄에 표시하도록 UI를 수정했습니다.
